# Learn C Programming

A collection of beginner-friendly C programs designed to help you learn
the fundamentals of C programming through simple examples.

## Topics

1. Variables
2. Input & Output
3. If / Else Statements
4. Loops
5. Functions
6. Arrays
7. Strings
8. Pointers
9. Structs
10. File Handling

## How to Use

Download or clone this repository and open the `.c` files in your
favorite C development environment.

Each file focuses on a specific C programming concept and contains
simple examples you can experiment with.
